# super-dev-09-curso-sistema-shoppings
Projeto em dupla desenvolvido pro curso pra colocar em prática FastAPI e MySQL. Criamos uma API pra gerenciar redes de shopping centers, cobrindo a administração de unidades, lojas, clientes, estacionamento e contratos de aluguel através de um banco de dados relacional com 7 tabelas interligadas.


## Instalação

Criar env: `py -m venv env`

Ativar env Windows: `env\Scripts\activate`

Ativar env Linux: `source env/bin/activate`

Instalar uma dependencia: `pip install <nome>`

Salvar quais dependencias o projeto tem: `pip freeze > requirements.txt`

Instalar todas as dependencias do projeto: `pip install -r requirements.txt`

Desativar env: `deactivate` 

Fluxo de novo projeto:
```shell
py -m venv env
env\Scripts\activate
pip install "fastapi[standard]"
pip freeze > requirements.txt
```
